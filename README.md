# テロップ用フォント ライブラリ

Instagramリール用のオープニング動画ツールで使う、**無料・商用利用可・再配布可**のフォントを集めるローカル用ライブラリです。

## 使い方

1. このフォルダをGitHubリポジトリにして、PCにクローンする
2. `START.BAT` をダブルクリック
3. メニューで `1`（日本語対応フォントを収集）を実行
4. `3` でプレビューを開き、実際のテロップ文言で見た目を確認
5. `4` でGitHubに保存

必要なのは Python 3 と Git だけです（追加パッケージ不要）。

## フォルダ構成

```
START.BAT          操作メニュー
fetch_fonts.py     収集スクリプト
preview.html       プレビュー（自動生成）
fonts/
  catalog.json     フォント名・配布元・ライセンス・取得日（アプリ読み込み用）
  catalog.csv      同じ内容（Excelで確認用）
  <フォント名>/    フォントファイル + ライセンス文書(OFL.txt等) + METADATA.pb
```

## ライセンス方針

収集対象は、Google Fonts のうち次の3種類のライセンスのフォントだけです。

| ライセンス | 商用利用 | 動画・SNS投稿 | 再配布 |
|---|---|---|---|
| SIL Open Font License 1.1 | 可 | 制限なし | 条件付きで可 |
| Apache License 2.0 | 可 | 制限なし | 可 |
| Ubuntu Font License 1.0 | 可 | 制限なし | 条件付きで可 |

- 有料フォント、Fontshare（独自ライセンス）は対象外です。
- 各フォルダに配布元のライセンス文書を一緒に保存します。
- 自分の動画に使うだけなら、フォントの表示・書き出しに制限はありません。
- リポジトリをpublicにすると「再配布」にあたります。OFL等は許可していますが、ライセンス文書を同梱したまま公開してください。気になる場合はprivateリポジトリが安全です。

## 注意

- フォントは合計で数百MB規模になることがあります。GitHubは1ファイル100MBまでなので、超えるファイルがあった場合は警告が出ます（Google Fontsの日本語フォントは通常これ以下です）。
- GitHubの無認証APIには回数制限があります。エラーが出たら環境変数 `GITHUB_TOKEN` を設定して再実行してください。

## Google Fonts 以外のフォントを追加する（半自動）

1. Claudeにスクショやフォント名を送り、候補の特定と、配布元の利用条件の確認をしてもらう
2. 動画・SNS投稿・商用利用が可と確認できたものだけ、`queue.json` に記録される（`verdict: "ok"`）
3. 配布ページでダウンロードした zip/ttf/otf を `inbox` フォルダに入れる（直リンクがあれば自動）
4. `START.BAT` の `6` を実行 → `fonts/` に展開され、規約の確認元URLと確認日が `catalog.json` に残る

`queue.json` の例:

```json
[
  {
    "name": "フォント名",
    "id": "font-name",
    "japanese": true,
    "verdict": "ok",
    "source_url": "配布ページURL",
    "download_url": "",
    "license_summary": "商用利用可・動画/SNS投稿可（規約の要約）",
    "license_url": "規約のURL",
    "checked": "2026-11-16"
  }
]
```

`verdict` が `ok` でないもの、規約の要約とURLが空のものは取り込まれません。
Instagram・CapCutなどアプリ内蔵のフォントは、アプリ内だけの利用許諾のことが多く、対象外です。
